# Wezan 🩺

Wezan is an iOS application designed to help people with diabetes monitor their daily health by tracking blood glucose readings and insulin doses in a simple and user-friendly interface.

## Features

- 📊 Record blood glucose readings
- 💉 Log insulin doses
- 📜 View history of glucose readings and insulin records
- 📈 Visualize glucose trends
- 👤 User authentication
- 🌙 Clean and accessible interface

## Technologies

- Swift
- SwiftUI
- SwiftData
- MVVM Architecture
- Xcode

## Architecture

The application follows the **MVVM (Model–View–ViewModel)** architecture.

- **Model** – Represents the application's data.
- **View** – Displays the user interface.
- **ViewModel** – Handles business logic and connects the View with the Model.

```bash

```

2. Open the project in Xcode.

3. Build and run on an iOS simulator or a physical device.
